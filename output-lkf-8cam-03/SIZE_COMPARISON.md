# 8 相机头盔 3×3 cm Marker 数据集评测

## 数据差异

- 数据集：`dataset-8cam-03/dataset_helmet_layout01_1m_dynamic_0001`
- 输入：8 路 H.264 MP4，1280×720，30 FPS，180 帧
- 相机、轨迹、Marker 局部坐标和全部 GT 文件与 `dataset-8cam-02` 相同
- 明确变化：Marker 缩放由约 3×4 cm 改为约 3×3 cm
- 正式检测面积范围：2～1500 px²；二维匹配门限：8 px

数据集自带验证报告仍称 Marker 为 3×4 cm，但实际 `rigid_bodies.json` 的六个 Marker 均为 `[0.03, 0.03, 0.002]`，因此本报告按 3×3 cm 处理。

## 与 3×4 cm 版本对比

| 指标 | 3×4 cm（8cam-02） | 3×3 cm（8cam-03） | 3×3 cm 变化 |
|---|---:|---:|---:|
| 二维表观召回率 | 64.21% | 64.29% | +0.08 个百分点 |
| 二维中心 RMSE | 2.2218 px | 2.2233 px | +0.07% |
| 3D Marker 平均误差 | 2.0163 mm | 2.0515 mm | +1.75% |
| 基础位置平均误差 | 1.3150 mm | 1.4584 mm | +10.90% |
| 基础姿态平均误差 | 0.3260° | 0.3297° | +1.14% |
| 优化后位置平均误差 | 1.0656 mm | 1.1663 mm | +9.45% |
| 优化后姿态平均误差 | 0.2553° | 0.2876° | +12.65% |

缩小 Marker 没有损害多视图覆盖，但总体位姿精度略有下降。逐点看，H05 的三维误差从 1.6660 mm 降到 1.1902 mm，H06 略有改善；H01～H04 则上升约 4.6%～14.2%，其影响超过了 H05/H06 的收益。就当前相机、轨迹和检测器而言，3×4 cm 版本的最终刚体位姿更准确。

## 结果边界

- Marker ID 使用 GT 投影辅助 Hungarian 匹配，本次不评估真实无标签 ID 关联。
- `visibility.json` 未做物理遮挡测试，64.29% 是相对于理论画面内投影的表观召回率。
- 正式输入为 MP4，验证报告中关于 1440 张 PNG 的描述与实际目录不一致。
- 3×3 与 3×4 版本除了视频渲染和 Marker 尺寸外，几何 GT 完全一致，因此本次尺寸对比具有较好的可比性。
