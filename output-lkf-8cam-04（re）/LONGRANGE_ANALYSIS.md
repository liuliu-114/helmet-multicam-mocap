# 8 相机长距离动态头盔评测

## 数据集概况

- 数据集：`dataset-8cam-04/dataset_helmet_longrange_dynamic_0001`
- 输入：8 路 H.264 MP4，1280×720，30 FPS，300 帧，10 秒
- 轨迹：沿 X 方向移动 7 m，速度约 0.70 m/s
- 相机到头盔原点距离：1.36～7.88 m
- 相机到 Marker 距离：1.25～7.99 m
- 每帧理论有效相机：4～8 台，平均 6.45 台
- Marker：沿用 Layout01 的六个 3×3 cm Marker

重新计算了 1800 个刚体 Marker 世界坐标和 11680 个画面内二维投影。刚体变换最大误差为 `6.45e-14 cm`，二维重投影最大误差为 `7.06e-5 px`，GT 几何一致。

## 正式协议

- HSV 红色检测 + 3×3 闭运算 + 连通域质心
- 连通域面积范围：15～500 px²
- GT 辅助 Marker ID 匹配门限：8 px
- 初始位姿：多视图 DLT + Kabsch
- 最终位姿：Huber 多相机 6DoF 重投影联合优化

远距离的 1～3 px² 连通域提供了少量额外观测，但中心噪声更大。15 px² 下仍能保证全部 300 帧有基础位姿和联合优化结果，因此正式结果采用 15～500 px²。

## 结果边界

- Marker ID 仍由 GT 投影辅助 Hungarian 匹配，不代表真实无 GT 的关联能力。
- `visibility.json` 没有物理遮挡测试，召回率相对的是理论画面内投影。
- 输入为有损 H.264 MP4，远距离亚像素 Marker 容易受色度采样和压缩影响。
- 近场数据集与本长距离轨迹、相机布局完全不同，不应只按全局平均误差做直接优劣结论。
