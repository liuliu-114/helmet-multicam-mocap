# 12 相机 4 cm Marker 长距离动态评测

## 数据集核对

- 数据集：`dataset-12cam-02/dataset_helmet_longrange_12cam_dynamic_0001`
- 输入：12 路 H.264 MP4，1280×720，30 FPS，300 帧，10 秒
- 轨迹：沿 X 方向移动 7 m；相机到头盔原点距离 1.36～7.88 m
- Marker：6 个圆形 Marker，尺度由上一版的 `0.03 × 0.03` 增至 `0.04 × 0.04`
- 直径变化：3 cm → 4 cm，直径增加 33.3%，圆面面积理论增加 77.8%

逐文件校验表明，新旧数据集的 `camera.json`、二维/三维 GT、头盔位姿、覆盖范围、距离和可见性标注完全一致；`scene_config.json` 也一致。除重新渲染的视频外，刚体文件中唯一变化是六个 Marker 的圆面尺度，因此本次适合用于观察 Marker 直径变化的影响。

## 正式流程与参数

1. 顺序解码 12 路 MP4。
2. HSV 红色分割、3×3 闭运算和连通域质心检测。
3. 使用 GT 投影辅助给无编码红点分配 H01～H06 ID，匹配门限 8 px。
4. 每个 Marker 使用多相机 DLT 三角化，再用 Kabsch 得到基础头盔位姿。
5. 以基础位姿为初值，使用 Huber 损失联合最小化所有有效二维 Marker 的重投影误差，优化头盔 6DoF。

根据本数据集的实际连通域面积扫描，正式面积门限选为 40～500 px²。这个下限约等于旧 3 cm 数据正式门限 25 px² 按圆面积比例放大后的 44 px²，并在有效 Marker 数量、最终位姿误差和尾部误差之间取得较好折中。

Kabsch 每帧使用 4～6 个成功三角化的 Marker，其中 245 帧使用完整六点。联合优化每帧直接使用 12～24 个二维观测，平均 16.46 个；观测来自 5～8 台相机，平均 6.08 台；每帧均包含六个 Marker ID。

3D 最大误差来自第 58 帧 H02 的两视角三角化，另有第 40、51 帧 H04 等少量两视角离群点。它们拉高了 3D RMSE，但 P95 仍为 4.95 mm。最终 6DoF 优化不是先完全相信这些 3D 点，而是回到各相机二维观测，并用 Huber 损失降低离群观测权重，所以最终位姿最大位置误差仍从 6.58 mm 降至 3.18 mm。

## 与上一版 3 cm Marker 对比

两版相机、轨迹和 GT 完全相同。下表使用各自经扫描选择的正式面积门限：旧版 25～500 px²，新版 40～500 px²。

| 指标 | 3 cm Marker | 4 cm Marker | 变化 |
|---|---:|---:|---:|
| 二维匹配数 | 4643 | 4937 | +294 |
| 表观召回率 | 38.75% | 41.20% | 相对提高 6.33% |
| 二维中心 RMSE | 0.952922 px | 0.940041 px | 降低 1.35% |
| 有效 3D Marker | 1712 | 1742 | +30 |
| 3D Marker 平均误差 | 3.404512 mm | 3.365471 mm | 降低 1.15% |
| 3D Marker RMSE | 3.533424 mm | 3.747142 mm | 增加 6.05% |
| 基础位置平均误差 | 2.643819 mm | 2.514257 mm | 降低 4.90% |
| 基础姿态平均误差 | 0.956479° | 0.993187° | 增加 3.84% |
| 优化后位置平均误差 | 2.400591 mm | 2.231957 mm | 降低 7.02% |
| 优化后姿态平均误差 | 0.838149° | 0.816088° | 降低 2.63% |

结论：Marker 从 3 cm 增至 4 cm 后，可检出观测和三角化覆盖率提高，最终位置误差改善较明显，最终姿态误差小幅改善。收益不是所有中间指标都单调变好：少量弱几何两视角点让 3D RMSE 上升，基础姿态也略差；刚体联合优化利用全相机、全 Marker 约束后，最终结果仍优于旧版。

## 结果边界

- Marker ID 使用 GT 投影辅助 Hungarian 匹配，当前结果不代表真实无 GT 的跨相机关联能力。
- 可见性标注不包含物理遮挡测试，所以“表观召回率”以理论画面内投影为分母。
- 输入是有损 H.264 MP4，远距离圆斑会受到压缩、色度采样和亚像素质心偏差影响。
- 正式面积门限使用本数据集 GT 误差扫描得到，只适用于此次离线评测；真实部署应使用置信度、视角几何和时序一致性进行动态加权。
