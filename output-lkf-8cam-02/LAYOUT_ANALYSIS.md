# 8 相机头盔 Layout01 数据集评测说明

## 数据与协议

- 数据集：`dataset-8cam-02/dataset_helmet_layout01_1m_dynamic_0001`
- 输入：8 路 H.264 MP4，1280×720，30 FPS，180 帧
- 正式检测面积范围：2～2000 px²
- 二维匹配门限：8 px
- 基础位姿：多视图 DLT + Kabsch
- 最终位姿：以基础位姿为初值的 Huber 6DoF 多相机重投影优化

数据集自带几何审计通过，相机内外参与上一版 `dataset-8cam-finetunning` 完全一致。本版除 Marker 位置外，还把贴片缩放从约 3×3 cm 改为约 3×4 cm，并直接采用 MarkerVisual 组件 Pivot 作为 GT 锚点。

二维检测共匹配 5548/8640 个理论画面内观测，表观召回率 64.21%，中心 RMSE 为 2.221752 px。六个 Marker 共形成 1080/1080 个逐帧三维点，三维平均误差 2.016273 mm，RMSE 2.111807 mm。

## 结果边界

- Marker ID 仍由 GT 投影辅助 Hungarian 匹配，本次主要评估检测、三角化和位姿精度，不代表真实无标签 ID 关联能力。
- `visibility.json` 未进行物理遮挡测试，因此 64.21% 是相对于“理论中心落在画面内”的表观召回率。
- 正式输入是 MP4；数据集验证报告中关于 PNG 数量的描述与实际目录不一致。
- 相比上一版同时改变了 Marker 位置、贴片尺寸和 GT 锚点，不能把全部改善只归因于位置调整。
