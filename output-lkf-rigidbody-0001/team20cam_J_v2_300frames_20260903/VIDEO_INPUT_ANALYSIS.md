# 20相机视频输入误差测试

## 测试对象

- 数据集：`dataset_rigidbody_0001/team20cam_J_v2_300frames_20260903`
- 输入：`videos/Camera_01.mp4`～`Camera_20.mp4`
- 视频编码：H.264 High Profile，YUV420P
- 分辨率：1280×720
- 帧率：30 FPS
- 帧数：每路300帧，共6000个相机帧

20路视频均可正常解码，帧数、分辨率和帧率一致。

## 测试流程

本次明确强制读取MP4视频，不读取同目录中的PNG图像。其余流程与PNG正式测试保持一致：

1. HSV红色区域提取和3×3闭运算；
2. 红色强度加权圆心；
3. 连通区域面积范围10～2500 px²；
4. GT辅助Hungarian Marker编号，匹配门限8 px；
5. 20相机多视图DLT三角化；
6. Kabsch计算初始头盔位姿；
7. Huber损失、2 px尺度的6DoF联合重投影优化。

另外扫描了10～200 px²的最小面积门限，并对10、15和60 px²候选进行了完整联合优化。10 px²方案的综合位置和姿态误差最低，因此作为正式结果。

## 与无损PNG输入对比

## 结论

H.264视频仍能稳定完成全部300帧定位，6个Marker在所有帧中均形成有效三维结果，最终位置平均误差为0.516 mm，姿态平均误差为0.337°。

与无损PNG相比，视频压缩使Marker边缘和颜色发生轻微变化，减少了187个有效二维观测，并使二维圆心RMSE增加约7.54%。该偏差继续传递到三角化和位姿计算后，最终位置平均误差增加12.15%，姿态平均误差增加15.59%。因此，这套数据误差较小并不完全依赖PNG；改用视频后仍保持亚毫米位置误差，但无损PNG确实提供了更高精度。

## 说明

当前Marker编号仍使用GT投影辅助匹配，本结果用于单独评估视频压缩对检测、三角化和位姿精度的影响，尚不代表无GT自动编号条件下的完整在线系统精度。
