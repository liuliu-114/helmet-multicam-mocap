# dataset-8cam-04 长距离 8 相机评测

## 数据集核对

- 输入：8 路 H.264 MP4，1280×720，30 FPS，300 帧（10 秒）
- 轨迹：沿 X 方向运动 7 m，头盔到相机距离 1.36–7.88 m
- 覆盖：每帧至少 4 台、平均 6.45 台、最多 8 台相机满足预检要求；失败帧 0
- Marker：H01–H06，3×3 cm；刚体模板与逐帧 GT 三维点一致
- 可见性只检查投影是否在画面内，没有物理遮挡标注

## 流程与参数

- 视频红点检测：HSV 红/橙阈值、3×3 闭运算、连通域质心
- Marker ID：使用 GT 投影进行 Hungarian 辅助匹配，门限 8 px
- 三维恢复：各 Marker 使用多相机线性 DLT
- 初始位姿：DLT 三维点与 `rigid_bodies.json` 模板进行 Kabsch/SVD 刚体对齐
- 联合优化：Huber 损失，尺度 1 px，最多 150 次函数计算
- 500 与 1500 px² 最大连通域上限得到完全相同的检测和位姿结果；长距离正式参数建议保留 500 px²

## 二维检测与三角化

- 理论画面内观测：11680
- 匹配观测：5703，表观召回率 48.83%
- 二维中心平均误差：0.9067 px；RMSE 1.0006 px
- 三角化 Marker：1774 / 1800
- 3D Marker 平均误差：5.0201 mm；RMSE 5.2353 mm
- Kabsch 有效位姿：300 / 300 帧；每帧 Marker 数 5–6，平均 5.91

## 结论和边界

- 全流程成功完成，300 帧均得到并优化了位姿。
- 长距离下二维质心误差仍约 1 px，但深度几何会放大到约 5 mm 的单 Marker 三维误差；刚体约束和联合重投影优化把最终位置误差压到约 3.20 mm。
- 自动生成的 `RESULTS.md` 中“近场 Marker 面积增大、500 px² 会误删”的固定文案不适用于本数据集；两种上限结果完全一致。以本报告为准。
- 当前 ID 关联仍使用 GT 投影辅助，因此结果评估的是检测、几何恢复和位姿优化，不代表无 GT 的真实 Marker 关联能力。
- `visibility.json` 没有物理遮挡测试，48.83% 是相对于理论画面内投影的表观召回率。
- GT 像素基线误差接近零，说明相机矩阵、坐标系、刚体模板与 GT 数据内部一致。
