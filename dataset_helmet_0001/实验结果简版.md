# 头盔运动捕捉实验结果（简版）

## 实验条件

- 数据集：`dataset_helmet_0001`
- 输入：4 台相机、360 张 PNG、1280×720、30 FPS、90 帧
- 相机到头盔距离：1.245–1.934 m
- 头盔 Marker：H01–H06
- 方法：红色 Marker 检测、GT 辅助 ID 匹配、四相机 DLT 三角化、Kabsch/SVD 位姿估计

## 核心结果

| 指标 | 结果 |
|---|---:|
| 有效位姿帧 | 90/90（100%） |
| 有效三维 Marker | 359/540（66.48%） |
| 二维中心误差 Mean / RMSE | 1.770 / 2.246 px |
| Marker 三维误差 Mean / RMSE | 3.385 / 3.756 mm |
| 位置误差 Mean / RMSE | **3.100 / 3.155 mm** |
| 位置误差 P95 / Max | 4.152 / 4.704 mm |
| 位置系统偏差 | 2.911 mm |
| 位置去偏 RMS | 1.215 mm |
| 姿态误差 Mean / RMSE | **1.102 / 1.133°** |
| 姿态误差 P95 / Max | 1.639 / 1.846° |
| 姿态系统偏差 | 0.994° |
| 姿态去偏 RMS | 0.545° |

## 结果说明

- 四相机能够恢复全部 90 帧头盔位姿。
- 实际位姿主要使用 H01–H04；H05/H06 未形成有效多视图三角化。
- 位置达到约 3 mm 量级；姿态约 1.1°，未达到 0.15° 目标。
- GT 用于检测后的 Marker ID 归属，本实验未验证完全自主的跨相机 ID 匹配。
- 数据为 UE 理想相机和红色 Marker，结果不等同于真实被动红外硬件验收。

## 结论

在 1.245–1.934 m 范围内，四相机头盔跟踪实现 100% 帧级覆盖，位置平均误差 **3.10 mm**，姿态平均误差 **1.10°**。位置达到数毫米量级，姿态未达到 0.15° 指标。
